## 🧪 Laboratorios

Laboratorios **1 al 20**, desde aplicaciones de consola hasta:

- Aplicaciones de escritorio con **Windows Forms**
- Sitios web con **ASP.NET Web Forms**
- Aplicaciones **ASP.NET MVC 5** y **Web API**
- Acceso a bases de datos con **SQL Server**

## ▶️ Cómo ejecutar

Abre el archivo `.sln` de cada carpeta con **Visual Studio 2022** y presiona **F5**.
